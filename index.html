Case Study: Nỗi ngợp trước giao diện

Mô phỏng quá trình chuyển đổi từ góc nhìn "Thị giác" (bị ngợp bởi màu sắc, chi tiết) sang góc nhìn "Cấu trúc" (bóc tách Box Model) để dựng khung HTML.

Góc nhìn thường gặp: Bị cuốn vào chi tiết (Bề mặt)

Khi nhận một bản thiết kế, các bạn mới học rất dễ bị "choáng ngợp" bởi quá nhiều chi tiết: từ màu nền, icon, cho đến các góc bo tròn... Thói quen tự nhiên là vừa gõ 1 thẻ HTML đã vội vã chuyển sang file CSS để chỉnh màu, ép vị trí cho giống hệt hình mẫu.

Bất cập của thói quen này:

Vì bỏ qua việc xây dựng bộ khung, các thẻ HTML sẽ nằm lộn xộn. Các bạn buộc phải lạm dụng margin âm, position: absolute hay float để "chắp vá". Kết quả là code cực kỳ rối rắm, và giao diện trông sẽ "méo mó" thế này đây:

HTML (Thiếu các thẻ <div> gom nhóm)
<img class="logo" src="logo.png">
<input class="search-box" placeholder="Tìm kiếm...">
<button class="btn-search">Tìm</button>
<div class="cart">Giỏ hàng</div>
<span class="badge-so-3">3</span>
<div class="user">Nhật Sơn</div>
CSS (Hậu quả: Phải dùng float, absolute để kéo vị trí)
.logo { float: left; margin-top: 25px; }
.search-box { position: absolute; left: 150px; top: 20px; }
.btn-search { margin-left: -5px; } /* Cố ép dính vào input */
.cart { float: right; margin-right: 50px; }
.badge-so-3 { position: absolute; right: -20px; } /* Bay lơ lửng */

Lời khuyên từ Mentor: Đeo "kính X-quang" để nhìn cấu trúc

"Khoan vội lo lắng về màu sắc hay CSS nhé. Các bạn hãy tập thói quen nhìn mọi thứ trên giao diện như những 'chiếc hộp' (Box Model).
Ví dụ ở Header này, nó đơn giản chỉ là 1 hộp lớn bên ngoài, chứa 3 hộp con nằm ngang bên trong: Hộp Logo, Hộp Tìm kiếm và Hộp Chức năng. Mình cứ gom nhóm và chia hộp chuẩn xác đã, việc trang trí tính sau!"

<header> (Container chính)
Khối 1: Logo [Hình ảnh Logo]
Khối 2: Tìm kiếm
[Ô nhập (Input)]
[Nút (Button)]
Khối 3: Actions [Thông báo] [Giỏ hàng] [Tài khoản]

Thành quả: Khung vững chãi, CSS cực kỳ nhẹ nhàng

Khi đã có bộ khung HTML chuẩn (được gom nhóm rõ ràng bằng các thẻ <div>), việc viết CSS trở thành "trò trẻ con". Thay vì chắp vá vất vả như Tab 1, chúng ta chỉ cần dùng Flexbox (dàn hàng) là mọi thứ sẽ vào hàng lối một cách hoàn hảo và tự động co giãn (responsive).

HTML (Gom nhóm thành 3 khối lớn)
<header class="main-header">
    
    <!-- Khối 1: Logo -->
    <div class="logo-box">
        <img src="logo.png">
    </div>

    <!-- Khối 2: Tìm kiếm -->
    <div class="search-box">
        <input type="text">
        <button>Tìm</button>
    </div>

    <!-- Khối 3: Actions -->
    <div class="actions-box">
        ...
    </div>

</header>
CSS (Chỉ cần dùng Flexbox)
.main-header {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

.search-box {
    display: flex;
    flex: 1; /* Tự giãn chiếm hết chỗ trống */
    margin: 0 40px;
}

.actions-box {
    display: flex;
    gap: 20px; /* Cách đều tự động */
}
